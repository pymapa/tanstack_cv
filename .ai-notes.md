## Decisions
- 2026-09-25: CV translation (EN ↔ FI) sends only listed text fields by JSON pointer, never the whole
  CV, and saves the reviewed result as a new CV version. Gated on `AI_PROVIDER` (`fake` | `anthropic`);
  the chat still only checks the API key.
- 2026-09-25: Chat work specs: PDFs go to Claude as document parts, text files as `<work_spec>` blocks.
  `checkAttachments` rechecks type, size, and count on the server. Links come only from the `linkCvs`
  tool, and chat markdown renders app paths only (no external links or images) against injection.
- 2026-09-25: `/?cv=[ids]` limits search to exact CV ids; the chat's "show these CVs" link uses it.
- 2026-09-25: The branding follows kipina.fi (palette/type read from its CSS) → the `kipina-brand` skill.
- 2026-09-25: The CV Zod schema is strict everywhere → unknown fields fail instead of vanishing.
- 2026-09-25: TanStack Start 1.168 uses `.validator()`; `inputValidator` is deprecated.
- 2026-09-25: PDF = Chromium `page.pdf({ tagged })` + pdf-lib metadata/`cv.json` attachment.
- 2026-09-25: `CvRepository` port + in-memory adapter now; the Postgres adapter comes in M1 behind the same interface.
- 2026-09-25: Database is PostgreSQL 17 in Docker (`pnpm db:up`), not SQLite (spec §15 D1, D10). `src/db/client.ts` has the pg pool.
- 2026-09-25: pnpm 11.3 pinned (the global install); `minimumReleaseAge` 24 h blocks brand-new releases.
