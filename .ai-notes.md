## Decisions
- 2026-09-25: Two chat agents: the CV bank agent (floating, `/api/cv-chat`, search tools) and the CV
  builder (`/cvs/new`, `/api/cv-builder-chat`). Builder tools run in the browser on the form draft only;
  the user creates the CV. Both routes share `handleChatRequest` (`src/lib/ai/chat-request.ts`).
- 2026-09-25: CV translation (EN ↔ FI) sends only listed text fields by JSON pointer, never the whole
  CV, and saves the reviewed result as a new CV version. Uses Claude when `ANTHROPIC_API_KEY` is set,
  like the chat; `AI_PROVIDER=fake` forces the offline fake (E2E).
- 2026-09-25: PDF template = `meta.x-template` + registry `src/pdf/template/templates.ts` (4 experimental entries to prune).
- 2026-09-25: "Save as new version…" copies the editor draft into a new variant (spec §7.3 updated);
  names are unique per person ignoring case. `createCvVariantFn` is open like the rest (`SECURITY TODO (spec M2)`).
- 2026-09-25: Chat work specs: PDFs go to Claude as document parts, text files as `<work_spec>` blocks.
  `checkAttachments` rechecks type, size, and count on the server. Links come only from the `linkCvs`
  tool, and chat markdown renders app paths only (no external links or images) against injection.
- 2026-09-25: `/?cv=[ids]` limits search to exact CV ids; the chat's "show these CVs" link uses it.
- 2026-09-25: Branding follows kipina.fi (`kipina-brand` skill). The CV Zod schema is strict everywhere.
- 2026-09-25: PDF = Chromium `page.pdf({ tagged })` + pdf-lib metadata/`cv.json` attachment.
- 2026-09-25: Drizzle added (spec §15 D11). First table `assistant_chat`: the CV assistant chat, per browser via the
  `cv_chat_owner` cookie until M2, attachments stored by name only, 90-day purge on save/clear. Integration tests
  create their own `cvbank_test_*` database (`tests/fixtures/db.ts`), so they need `pnpm db:up`.
- 2026-09-25: `CvRepository` port + in-memory adapter now; the Postgres adapter comes in M1 behind the same interface.
- 2026-09-25: Database is PostgreSQL 17 in Docker (`pnpm db:up`), not SQLite (spec §15 D1, D10). `src/db/client.ts` has the pg pool.
- 2026-09-25: pnpm 11.3 pinned (the global install); `minimumReleaseAge` 24 h blocks brand-new releases.
